## 프로모션 텍스트
현장에서 휴대폰으로 바로 여는 CAD 도면. DWG 변환까지 기기 안에서 처리해 인터넷 없이 열리고, 도면이 밖으로 나가지 않습니다.

## 설명
현장과 회의실에서 휴대폰으로 바로 여는 CAD 도면 뷰어입니다.

■ DWG · DXF 바로 열기
카카오톡·메일·파일 앱에서 받은 도면을 "공유 → DWG 뷰어"로 바로 엽니다. DWG 변환까지 기기 안에서 처리해 인터넷이 없어도 열립니다.

■ 손가락으로 편하게
한 손가락 이동, 두 손가락 확대, 두 번 탭 확대. 큰 도면도 구역별로 나눠 부드럽게 그립니다.

■ 거리 · 면적 측정
화면 가운데 십자선이나 원하는 곳을 탭해 측정합니다. 끝점·중간점에 자동으로 붙는 스냅을 지원합니다.

■ 레이어 · 문자 검색
레이어를 켜고 끄고, 도면 속 문자를 검색해 바로 찾아갑니다.

■ XREF 자동 연결
도면 폴더를 연결해 두거나 본 도면과 XREF 파일을 함께 고르면 외부 참조가 자동으로 붙습니다.

■ 화면 이미지 저장 · 공유
보고 있는 화면을 이미지로 저장하거나 바로 공유합니다.

■ 보안
- 회원가입·로그인 없음
- 도면을 서버로 보내지 않음, 수집하는 데이터 없음

■ 오픈소스
GNU LibreDWG(GPLv3)를 사용하며, 앱 전체 소스는 GitHub에 공개되어 있습니다.
https://github.com/JIKIHY/dwg-viewer-mobile

## 심사 메모 (영문)
DWG Viewer opens AutoCAD DWG/DXF drawings entirely on-device (DWG is converted to DXF locally with the bundled GNU LibreDWG WebAssembly module). No account, no login, no network access is required.

How to test:
1. Download the sample drawing: https://raw.githubusercontent.com/JIKIHY/dwg-viewer-mobile/main/samples/sample_floor_plan.dxf (save it to the Files app).
2. Launch the app and tap "도면 열기" (Open Drawing), then choose the sample file. You can also open any DWG/DXF from Files/Mail via Share > DWG Viewer.
3. Pinch to zoom, drag to pan. Bottom bar: 거리 (distance), 면적 (area), 레이어 (layers), 검색 (text search), 더보기 (more: background color, image share, license info).

External services: none. The UI is in Korean and works the same in all regions.
Open source: the app is GPLv3; full source code is at https://github.com/JIKIHY/dwg-viewer-mobile (license info in 더보기 > 정보 · 오픈소스 라이선스).
